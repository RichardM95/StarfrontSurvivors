# 星际前线：孤军生还 · V2 系统试玩版

Godot 4.6.3 Standard / GDScript，版本 **0.3.0-v2-mobile**。这是按《游戏系统设计与机制演化案 V2.0》重构的可编辑、离线俯视角生存肉鸽测试版，不是最终发行版。所有代码构建与验证在云电脑完成。

## 手机安装与操作

下载本次 `.7z` 附件，用支持 7z 的文件管理器解压，打开其中 APK。适用64位 ARM Android设备，最低 Android 7.0，需OpenGL ES 3.0。使用与上一版相同测试签名；包名相同，可以覆盖安装。不要关闭 Play Protect 等安全防护。没有应用商店发布，没有联网权限。

- 横屏；左半屏任意可操作区域按下生成浮动摇杆，拖动移动，自动瞄准射击。
- 右侧大圆按钮或快速划动冲刺；陆战队额外有兴奋剂按钮。
- 系统返回键暂停；后台切换自动暂停。触控摇杆与右手操作互不抢占。
- 波间先处理排队的三选一升级，再逛商店。四商品可锁定，武器可回收；最后一把武器不能回收。
- 武器升到三级必须二选一专精，一经选择本局不可改。
- 波间自动保存；点“保存并退出”返回菜单，下次选择“继续存档”。战斗中退出会回到此前波间检查点，不支持恢复战斗中的每一帧。
- 开始新局会明确提示覆盖旧局。旧0.2版只有最高波次统计，没有可迁移的局内构筑。

## 本版系统

五职业：陆战队（兴奋剂）、掠夺者（震荡减速）、收割者（双冲刺/跳雷）、火蝠（点燃殉爆/护甲）、幽灵（暴击/30杀EMP）。

四独立武器槽，可装重复武器；五种武器族，Lv1–4，三级A/B分支。实弹、等离子、爆破、高科技按2/4件生效。十二项属性与双曲线护甲；十件收益/代价道具。临时攻速、站定回复、受击注射、炮台、复活等在战斗中结算，不只是展示数值。

手动拾取补给积累过载，波后未拾取仅回收75%；升级排队到波间，三选一70/25/5权重，免费/5/10三次刷新。商店显式区分新购与升级、4个报价、锁定、过滤无用报价及50%已投入价格回收。

十个战术波次包含毒爆虫、地刺潜伏者；第十波三阶段首领拥有弹幕/践踏、虫茧/迫击炮、旋转光束/缩圈，必须击杀结束。

## 编辑与测试

导入 `project.godot`，Godot4.6.3运行F5；或 `godot --path .`。无需额外插件、账号、网络。桌面WASD/方向键移动，空格冲刺，P/Esc暂停，M静音；菜单可切换触控预览。

测试脚本：`godot --headless --path . --script tests/build_v2_test.gd`（其他测试替换文件名）。当前核心为 `main.gd` 调度/UI、`build_v2.gd`成长、`combat_v2.gd`战斗、`save_v2.gd`校验/恢复。旧 `tests/test_game.gd` 针对0.2数据结构，不是本版验收入口。

## 冲突处理与实现边界

- 护甲统一为点数，减伤 `armor/(armor+50)`，旧15%/10%换算约8.82/5.56点，不沿用另一套百分比叠加/70%封顶。
- 职业初始枪与商店武器统一为五族；所有武器都支持明确升级与三级分支。道具每种最多一件，避免负代价堆叠破坏状态。
- “+240%伤害”解释为总乘3.4；散弹贴脸分支采用贴脸伤害倍率而非超过100%的概率。波间额外回复12%最大生命，提升短局容错。
- 使用Godot4的display safe-area接口而非旧API；存档为小型同步校验JSON、临时文件原子替换和有效备份，不采用工作线程。只有已提交检查点可恢复。
- 使用空间哈希、固定预算与复用数据字典；程序化绘制特效而非GPUParticles2D节点。不能据此声称移动端50–60FPS或零GC。
- 模拟器/真实手机性能、发热、刘海适配、系统杀进程恢复、触控手感与长期数值平衡仍待验收。详细已验/偏差见 **QA_V2.md**；旧QA.md仅供历史参考。
