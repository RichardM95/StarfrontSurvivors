# v5 独立审计（持续集成记录）

范围：系统/UI v5 第16节验证切片。只在云端执行。不将完整设计表、受控机制测试或机器人模拟宣称为完整12波游戏、真实Android触控/热性能或平衡验收。

## 已发现并通知修复

- 战斗随机状态写成int64：JSON精度风险；改为字符串。
- T08爆炸半径重复扣除；同类攻速应先加后统一限幅；重甲必须是明确标签而非护甲>0。
- 跳虫移动停止距离大于接触攻击距离，导致停在判伤范围外。以固定种子W1无外部受伤现象结合源码定位。
- T11原始拾取价值及待触发标志曾被通用计时器扣减；应保留为计数/布尔量。
- 高优先首领危险不能总因较低优先危险被延后；未来危险计算须包含delay+warning。
- 模型耗尽货架生成空ID的已购占位，保存校验应识别而不拒绝合法存档。
- UI find_weapon将索引误当字典、启用池nested/flat字段不一致、放弃未真正清run、道具整种回收文案写成一份。
- 手机设计像素不能当dp/sp；密度换算后HUD固定坐标必须重排。
- 结局直接保存含Rect2的visible_world会失败；局外奖励保存失败不能忽略。

## 后续审计补充

- 同帧致死后S02/T01等治疗可能把hp0拉回正值，需拒绝无救命额度的零生命治疗。
- 暂停/后台清除触点所有权时必须同时重置move_finger，避免恢复后无法再获得摇杆。
- W12旋转束绘制把angle当中心角，战斗判定当起始角，曾偏移60°；应共用[h.angle,h.angle+h.arc]。
- 音量/危险震动等控件不能只保存数值而不接效果。未实现项应明确禁用/说明而非虚报。
