# 星际前线 孤军生还 v0.5.0 验证切片

依据系统设计稿 v5 第16节与配套 UI v5 重构。仅在云电脑开发、运行和打包；不是完整十二波战役。

## 本次可玩范围

- 职业 C01、C03、C06。
- 武器 W01、W02、W03、W05、W06、W07，均含 Lv3 A/B 分支。
- 支援 S01–S04；科技 T01/02/03/05/08/09/10/12。
- 道具 I01/02/11/12/13/18/21/22/25/31/32/37。
- 第一幕4波；可调敌人数与时长的压力房；独立W12首领试场，可选3科技及明确标记的测试军械预设。训练不产研究数据。
- 全部6职业、12武器24分支、8支援、24科技、40道具、8构筑保留完整参考资料；未开放内容仅供档案查看，不出售未实现内容。

## 操作

手机：左侧移动；右侧冲刺和职业技能。技能按住预览、松手施放，拖入取消区取消；点击敌人设置/取消集火。支持左右手和操作键布局。
云电脑：WASD/方向键移动，空格冲刺，E职业技能，Escape暂停；鼠标可操作触控区和集火。
整备可先购物，再处理升级/研究；未处理必要选择不能出击。W2研究使用20瓦斯。Lv3分支和满槽替换先比较再确认，取消不扣费。

## 旧档与保存

v5使用独立档案。原v2/v4存档保留，不直接导入旧装备、货币、永久属性或精研；旧行动不能直接续玩。研究数据只记录选择解锁，不增加永久战力。
每笔交易保存；波中恢复从波前快照重新开始，已消耗救命记录保留。损坏主档尝试有效备份，不能识别的ID不静默删除。保存失败会阻止离开整备，需重试。

## 已知差异

玩家武器使用即时命中与可视轨迹，敌酸弹真实飞行；危险出口采用离散采样，不是连续导航证明。人物/装备美术仍有共用矢量轮廓与占位图标，提示音为合成音，无真人配音。完整故事解锁/未读通信列表、独立字幕字号与背景透明度设置尚未制作。当前切片内容默认解锁，研究终端主要管理下局启用池。
固定种子改进机器人策略可完成四波，但首领用时22.60/21.10/19.83秒，低于60–90秒设计目标；隔离DPS检查与公式一致，未擅自改首领生命凑时长。原策略失败样本也保留。不能据此声称平衡通过。
未进行实体Android安装、连续三指握持、系统杀进程或10分钟热负载验收；未验证完整12波时间和8构筑各3局。

## 运行与测试

Godot 4.6.3，打开 project.godot。入口 scripts/main_v5.gd。
`./run-v5-tests.sh` 跑模型/保存/战斗/UI/音频/独立集成测试；`tests/ui_persistence_v5_test.gd`另验证真实UI保存链。
测试日志写入 test-results/，该目录为生成产物，不入库。
Android包 org.starfront.survivors，versionCode 6；导出使用 export_presets.cfg，产物写入 exports/。

## 导出说明
工程将工作线程池限制为 2（`threading/worker_pool/max_threads`），避免高核数环境自动创建过多工作线程。
Android 资源包的 mobile 特性在 headless 零像素物理屏幕下会令 dp 换算异常，smoke 测试需显式提供 density=1（`tests/exported_mobile_smoke.gd` 已处理）。此为桌面 headless 资源检查，不替代 Android 设备验收。
