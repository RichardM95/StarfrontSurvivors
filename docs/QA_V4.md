# 星际前线 v0.4.0 实现与验收报告

日期：2026年10月29日。依据用户上传《设计稿v4.md》，在 v0.3.0 原型上继续实现。所有开发、构建、自动测试和界面操作均在云电脑进行。本报告区分原稿要求、为形成可玩闭环所补充的设计，以及尚未验证的事项。

**结论：已形成30波、三战区、局内构筑与舰桥养成相连的离线试玩原型，不是正式发行版，也不代表全部设计和真机性能验收完成。** 当前玩法沿用既有俯视角竞技场生存肉鸽，不是横版平台跳跃游戏。

## 本版已实现

- **战役**：W1—10前哨废墟、W11—20熔岩矿区、W21—30母巢深渊。W10、W20击杀Boss后继续购物及下一战区；W30才结束战役。三Boss基础生命2800、6500、18000，分别提供酸液分裂/召唤/践踏、追击/钻地免伤/破土留巢、三阶段弹幕/虫茧/旋转光束及缩圈。沙暴、熔岩、毒雾、地刺与菌毯等危险随波次出现。
- **通讯**：30波开始与结束对白，W10/W20过渡、W30阶段和结局对白，商店情境对话、战斗事件短句、舰桥死亡复盘与研发对话。字幕逐字出现，可跳过、查阅通讯记录；不要求停下战斗读完长对白。最近600条通讯记录保存到本机JSON，支持重新打开后回看；不是无限容量的永久剧情收藏系统。
- **构筑**：保留五职业；八类商店主武器，每类可升级并选择分支，四个武器槽。收割者保留职业起始变体，不计作第九类商店武器。共有42件不同道具，新增工程标签。
- **支援**：哨戒炮、医疗无人机、渡鸦、蜘蛛雷独立于武器槽。哨戒炮持续攻击；医疗无人机定时回血及濒危保护；渡鸦每波最多拦截8枚酸弹；移动累计距离触发蜘蛛雷。工程两件提高支援射速，四件触发护盾。
- **养成**：瓦斯购买10项科技，基因片段购买3项卡片精研。三星分别把硬芯射速代价减为7.5%、增压泵生命代价减为5、步枪贯穿基础伤害代价减为10%。研发影响新部署；继续已有局保留该局原有科技及精研快照。
- **手机交互**：横屏浮动摇杆、自动射击、右侧冲刺/滑动冲刺、陆战队兴奋剂、升级三选一、商店锁定/购买/回收、暂停及波间保存。舰桥科技分页与精研页可实际消费资源。

### 新武器分支和其他补充值

- C10狙击：穿透4敌、伤害+25%而射速−15%；或暴击+25%、暴伤+0.5而基础伤害−10%。
- 榴弹：半径+40%而伤害−15%；或击晕0.6秒而射速−20%。
- 特斯拉：连锁7目标而伤害−15%；或麻痹0.8秒但只连锁3目标。
- 冲锋枪：射速+35%而伤害−15%；或穿透+2、伤害+15%而射速−20%。
- 等离子炮：光束伤害+35%而宽度−35%；或宽度+80%而伤害−20%。
- 原稿没有列全的基础伤害、波次持续时间、敌人刷新频率、预警时间、地图危险伤害、召唤节奏、护盾冷却和触发次数均由本版补齐。完整参数位于 `combat_v2.gd`；普通波时长约25—45秒，Boss波无倒计时自动获胜。
- 医疗无人机濒危3秒保护**每波一次**；工程四件30点护盾**12秒冷却**。这两个限制属于补充设计。
- 资源按清波结算：每波基因1；三区瓦斯依次3/5/7；每逢10波额外瓦斯12、基因6；最终胜利另加瓦斯25、基因12。未清完当前波就死亡不结算该波。不是击杀一只敌人就直接发局外货币。
- 保留波末12%最大生命回复、75%地面补给回收、科技最高90%回收；护甲采用 `armor/(armor+50)` 减伤。步枪“+240%伤害”按总计3.4倍解释。现有职业、分支和经济解释可见历史 `QA_V2.md`，与本版冲突时以当前代码及本报告为准。

## 存档与恢复的实际边界

局内使用校验JSON、临时文件写入、原子替换及有效备份；局外资源采用同类持久化。结算先提交带局ID/完成波次的奖励账本，再推进局内检查点；回放旧检查点不重复发放已登记奖励。奖励写入失败会回滚本次资源变化并阻止推进，胜利写入失败不会清除最后恢复点，可重试。

这不是跨文件数据库事务，也不是后台异步存档。局内与局外是有序提交的独立文件；仅承诺已提交的波间状态，不恢复战斗中的任意帧。v0.3.0检查点支持可行字段迁移，旧局缺少新字段时使用兼容默认值。校验用于发现损坏，不是防恶意改档或联网反作弊系统。

## 自动化与云界面验收

最终执行日志保存在项目 `test-results/v4/`。执行例：

```bash
XDG_DATA_HOME=/tmp/starfront-v4-isolated-qa godot --headless --path . --script res://tests/integration_v4_test.gd
```

新测试覆盖：构筑/科技/精研389项、叙事108项、战斗49项、集成290项。集成测试加速推进完整30波，核对三Boss生命、W10/W20非终局、重复结算不重复奖励、旧检查点回放、旧版迁移、科技和精研实际数值、实际90%回收，以及真实文件写入失败后的阻塞与重试。战斗测试对八武器各分支进行实际伤害检查，并验证四支援、三Boss机制及环境危害；不是仅检查配置表存在。

旧回归覆盖：构筑155项、战斗44项、集成69项、存档64项、音频路由/节流36项。音频测试不代表音频设备实际播放验收。最终统一重跑共**1204项通过，0项失败**，对应日志已逐项核对；未出现SCRIPT ERROR。中间一次测试退出曾有ObjectDB实例未释放警告，最终同批日志未再出现；仍不以断言全过代替长时间资源稳定性测试。

云桌面GUI已实际操作：舰桥科技/精研页面、首波通讯与移动实战、波间两次升级、商店购买渡鸦独立支援、保存退出后主菜单显示瓦斯3/基因1。通讯日志已在云界面验证可以完整回看，中文显示正常。此证据来自云桌面，不是Android触屏实机。

## 尚未完成或不能据此声称完成

1. **美术与演出**：程序化角色/敌人/场景和几何特效；头像是单字识别牌，不是成套角色肖像。无线电采用合成噪音/提示音，没有角色配音，没有真人音色克隆。过场通过对白、色调及场景状态切换表达，不是完整动画、坠机电影或轨道轰炸CG。
2. **技术方案差异**：主循环使用共享实体数组、空间哈希和受限复用字典，不是完整面向节点组件系统；特效不是GPUParticles2D。存档是小型同步JSON，不是后台线程。不能声称零分配、零GC或恒定60FPS。
3. **极端射速限制**：各主武器每次更新最多发射一次，保留冷却余量；在低帧率或叠加极高射速时实际射速受帧率限制。22发/秒配置不构成任何帧率下都能达成的保证。
4. **真机与系统**：未验证实体Android安装、覆盖升级、冷启动、系统强杀/掉电、低内存、磁盘满、长期发热、耗电、刘海/手势区、多指手感、音频设备及后台往返。云端写入失败注入不能替代手机系统强杀测试。
5. **平衡**：未完成30波各职业/各流派正常经济的人类通关验证、长期资源进度评估或全组合平衡。加速测试、直接击杀Boss的测试夹具不能作为正常玩家必定可通关的证明。
6. **作品定位**：这是非官方星际科幻同人试玩原型，不是暴雪官方产品。本报告不声称已获得品牌、角色或商业发行授权；当前没有商店发布或公开上线。
